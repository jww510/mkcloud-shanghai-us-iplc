## 先说清楚：这到底是什么产品

MKCloud 是 2023 年开始运营的国人商家，官网给自己的定位是"合规跨境电商专线服务器"，产品线覆盖广港 IEPL、沪日 IPLC、沪美 IPLC 等多条线路。沪美 IPLC 指的是上海入口、美国出口的国际私有专线电路，走的是上海电信接入的私有线路，直达美国 BGP 节点，官方给出的端内参考延迟是 124~134ms。

它和普通 VPS 有一个关键区别：交付形式是"专线 + VPS"，每台机器分配两个独立 IPv4，一个入口 IP 在上海，一个出口 IP 在美国。你连入口操作机器，程序从美国出口向外访问。因为跨境段走的是私有线路，不经过公网，所以 IP 不存在被墙的问题，延迟也不会因为公网拥塞大幅波动。

不过有一点容易被误解。124~134ms 指的是上海到美国出口这段的端内延迟，不是你访问所有美国网站的总延迟——出口之后到目标服务器还有一段路径。MKCloud 自己的知识库里专门强调了这一点，提醒用户不要把端内延迟当成全程 RTT。跨境选型要分段看：本地接入、跨境线路、美国出口后的路径、目标服务负载，四段共同决定体验。

## 共享和独享，差价近一倍，选哪个

这两类产品的计费逻辑完全不同，选错了要么浪费钱，要么跑不动业务。

**共享带宽按流量计费**。你选的是"峰值带宽 + 月流量"的组合，比如 2TB 流量档是 300M 峰值。注意"峰值"的意思：它能瞬时跑到 300M，但不保证持续跑满。流量按上行和下行双向统计，用超了系统会暂停服务，等下个流量重置周期恢复，或者自助购买流量重置、提交工单补差价升级。适合流量能预估、间歇性使用的场景，比如美区店铺后台、API 调用、远程办公。

**独享带宽按带宽计费**。选的是固定速率，比如 10M 就是稳定 10M，流量不限。适合需要持续传输的业务——固定速率的文件同步、素材上传、数据回传。代价是单价高：5M 起步就要 800 元/月，10M 到 1100 元，带宽每上一个台阶价格跳得很明显。

一个粗略的换算：10M 独享如果 24 小时跑满，一个月理论上能跑 3TB 左右，这个量买共享套餐要 1258 元（4TB 档）。所以如果你的业务是长时间持续传输，独享反而划算；如果只是工作时段访问后台、偶尔传文件，共享更省钱。MKCloud 知识库的建议也是先统计月流量和持续速率，再决定走哪条计费路线。

## 买之前必须知道的几条规矩

这部分比延迟和价格更重要，因为它直接决定你能不能用、能不能退：

1. **实名认证**。所有专线产品需要中国身份信息实名，国内手机号 + 身份证号 + 姓名一致性验证，不支持绕过。
2. **省级白名单**。为防止机场、回国等违规用途，产品只允许你下单时选择的那一个省份的 IP 连入。省份后续可以自助修改，但同一时间只认一个省。如果你的出口 IP 会在多个省份之间漂，这个限制要认真考虑。
3. **退款政策严格**。只支持质量问题退款，且需要提供准确具体的延迟、速度数据作为证据；服务开通后不支持更换到其他地域的产品。
4. **出口 IP 不支持外部连入**。美国那头的出口 IP 不能用来建站、承接支付回调或跑游戏服务端，它只是给机器对外访问用的。官网知识库把这条写得很直白：它不是办公室到美国云 VPC 的互联服务。

付款方面支持支付宝，支持月付——按月付意味着试错成本可控，跑路风险相对低，这也是第三方测评特别点出的一条优点。

## 常见问题

**沪美 IPLC 的 124ms 是访问所有美国网站的总延迟吗？**

不是。这是上海入口到美国出口的端内参考延迟，出口之后到目标网站的路径另算。访问具体网站的体验要分段看。

**流量双向计费是什么意思？**

上行和下行都算流量。比如下载 10GB + 上传 2GB，消耗的是 12GB。测算套餐够不够用时，要按双向总和估。

**超流量之后会怎样？**

共享带宽套餐超量后系统暂停服务，下个流量重置周期恢复，也可以自助购买流量重置或提交工单补差价升级套餐。独享带宽不限流量，但受配置速率限制。

**可以换省份连入吗？**

可以。下单时选择初始省份，开通后可自助修改为其他省份，但同一时间只允许一个省份的 IP 连入。

**最低多少钱能开始用？**

按当前商店页展示，共享带宽 1TB 流量档 428 元/月是最便宜的现售档位；如果有活动价或旧套餐回流，以结算页实际显示为准。独享带宽起步 800 元/月（5M 档）。

**支持哪些系统？**

下单时可选择 Ubuntu 20.04/22.04/24.04、Debian 11/12/13、CentOS Stream、AlmaLinux、Rocky Linux 等主流发行版，KVM 虚拟化，装机流程全自动，官方称约 1 分钟开通。
